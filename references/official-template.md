# 可选官方模板

资源：[official-template.docx](../assets/official-template.docx)。来自用户提供的《电子系实验报告模版.docx》，按原始字节保留。只有选择该模板时使用；它不代表所有课程的最新强制要求。

## 已核对的结构

| 项目 | 原文件内容或属性 |
|---|---|
| 页面 | A4；上下边距 25.4 mm、左右 31.75 mm |
| 页眉 | 左侧示例课程名 Microwave Engineering（一个 22 pt 的文字 run）+ 右侧校标。**必须替换成实际课程名** |
| 标题 | 示例 Lab 1：Magic T-junction；居中，普通正文段落，无标题样式 |
| 表格 | 2 列 4 行 |
| 第 0 行 | Authors \| Name、Student ID |
| 第 1 行 | **gridSpan=2 的合并单元格，Objective 与 Lab results & Analysis 同在这一格里** |
| 第 2 行 | gridSpan=2 的合并单元格，Experience |
| 第 3 行 | Score \| 空，留给评分 |
| 样式 | 只有 Normal、Header、Footer 和表格样式，**没有任何标题样式**，需自行创建 |
| 明确字体提示 | 英文使用 Times New Roman |
| 内容提示 | 解释公式符号，注明图中的坐标和单位 |

这些信息来自文本和 OOXML 结构检查；下列排版行为在 EE323 Lab 2 上实测确认。使用时仍要渲染实际生成的报告，不能据此保证任何编辑工具中的分页完全一致。

## 整篇正文在一个表格单元格里的后果

第 1 行是跨列合并单元格，报告正文全部嵌套在这一个单元格内部。Word 在这种结构下
**不遵守若干排版属性**，实测（检查过生成的段落 XML，属性确实写入）：

- **嵌套表格的 `w:tblHeader` 不重复表头。** 表格跨页时表头不会在续页重现。
- **`w:keepNext` 被忽略。** 段落里写入了 `w:keepNext`，Word 仍会把标题留在页脚；
  嵌套表格各行之间的 keep-with-next 同样无效。表格无法靠加属性保持整块。
- **短表格会在表头之后断开。** 表格起点距页脚不足约两行时，表头留在上一页、
  数据行落到下一页。
- **H1 若带 keep_with_next，会把整个第 1 行推到下一页。** 结果是第 1 页只剩标题和
  Authors 行，约 20 cm 空白，总页数 +1。去掉 H1 的 keep 后即恢复正常。

可用的对策：

- 表格**题注放表格上方**。表题是普通段落，字号与位置都可控；这样最坏情况下
  孤立的是表题与表头，而不是表题被甩到续页。
- 表格行的 keep-with-next 可以保留，无害即可。
- 要让一张表格整块落在当前页，**唯一有效的办法是缩小它前面的图**，让表格正好装得下。
- **不要用硬分页修**。用户还要往 Experience 等栏目填内容，一分页就会错位。
- H1 默认不加 keep_with_next；只有某个标题确实被留成页脚孤行时，再对该段单独设置。
- 创建标题样式时用真正的段落样式，不要靠加粗和字号模拟。

## 图的可读性要在印制尺寸上算

嵌入文档后图会按插入宽度缩放，源图清晰不代表印出来可读。按下式核对：

```
等效字号 = 源图字号 × (印制宽度 ÷ 图逻辑宽度)
```

图逻辑宽度取 `PNG 像素 ÷ 300`（MATLAB `exportgraphics` 与 matplotlib 300 dpi 输出均适用），
或 matplotlib 的 `figsize` 英寸值。正文区宽 14.65 cm，插图一般不超过 13.8 cm。

实测教训：7 in 宽的 MATLAB 图按半栏 6.6 cm 插入，等效字号只有 3.2 pt，完全不可读；
两个半栏宽的多面板图改为整栏插入后升到 7.9 pt。目标取 **≥7 pt**。

图偏大时优先**按最终印制宽度重画源图**（缩小 `figsize` 或调整 `Position`），
而不是把插入宽度调大或缩小字号——前者同时改善可读性与版面。

## 如何适配

1. 复制资源后编辑。校标直接复用原件，避免重绘或更换成不相关标识。
2. **页眉换成实际课程名**。模板页眉里是示例课程 Microwave Engineering，属于变量，不是默认事实。入口询问里已经收过课程或项目名，用它替换页眉段落中那个文字 run——带中文时要同时设置该 run 的 `w:eastAsia` 字体，否则可能回退成默认字形。校标不动。
3. **标题只写实验或项目名**（如「实验二：离散时间系统」），不要再重复课程名：课程已经由页眉承担，两处都写会显得冗余。标题在模板里是居中的普通段落，保持居中即可。作者信息按用户提供的真实姓名和学号填。
4. 默认保留固定栏目及表格外观，在 Lab results & Analysis 内按任务使用子标题。用户另有要求时按其选择调整；用户不要的栏目（如 Experience）整行删掉，比留一个空框干净。
5. 空行和行高用于空白表单，不代表必须保留相同空白面积；填入内容后合理调整分页，核对表格跨页和边框。
6. 中文正文字体与字号在原件中没有被上述英文提示完整规定。采用清晰且可用的字体，并根据当前课程要求决定，不能把其他个人报告的字体推断为官方规范。
7. Experience 填写时基于真实记录，没有就整行删掉，不代填；Score 留给评分，不能从样例继承或自行填写。正式交付移除不需要的写作提示、示例文字和无意义空白。

如果用户要求用 LaTeX 或 Typst 复现官方外观，以原件为视觉依据并验证结果。不要在需要提交可编辑 Word 的课程中未经确认地改用另一种源格式。
