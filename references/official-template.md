# 可选官方模板

资源：[official-template.docx](../assets/official-template.docx)。来自用户提供的《电子系实验报告模版.docx》，按原始字节保留。只有选择该模板时使用；它不代表所有课程的最新强制要求。

## 已核对的结构

| 项目 | 原文件内容或属性 |
|---|---|
| 页面 | A4；上下边距 25.4 mm、左右 31.75 mm |
| 页眉 | 示例课程名 Microwave Engineering 和校标 |
| 标题 | 示例 Lab 1：Magic T-junction |
| 栏目 | Authors、Objective、Lab results & Analysis、Experience、Score |
| 作者信息 | Name、Student ID |
| 版面 | 黑色表格边框；存在填写用的空行和最小行高 |
| 明确字体提示 | 英文使用 Times New Roman |
| 内容提示 | 解释公式符号，注明图中的坐标和单位 |

这些信息来自文本和 OOXML 结构检查。打包时未完成原文件的独立页面渲染，因此使用时仍要渲染实际生成的报告，不能据此保证任何编辑工具中的分页完全一致。

## 如何适配

1. 复制资源后编辑。校标直接复用原件，避免重绘或更换成不相关标识。
2. 替换课程名、实验编号、题名和作者信息。示例课程和题名是变量，不固化为每次任务的默认事实。
3. 默认保留固定栏目及表格外观，在 Lab results & Analysis 内按任务使用子标题。用户另有要求时按其选择调整。
4. 空行和行高用于空白表单，不代表必须保留相同空白面积；填入内容后合理调整分页，核对表格跨页和边框。
5. 中文正文字体与字号在原件中没有被上述英文提示完整规定。采用清晰且可用的字体，并根据当前课程要求决定，不能把其他个人报告的字体推断为官方规范。
6. Experience 基于真实记录；Score 留给评分，不能从样例继承或自行填写。正式交付移除不需要的写作提示、示例文字和无意义空白。

如果用户要求用 LaTeX 或 Typst 复现官方外观，以原件为视觉依据并验证结果。不要在需要提交可编辑 Word 的课程中未经确认地改用另一种源格式。
